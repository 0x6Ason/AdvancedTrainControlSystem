# Contributing

Thank you for looking at ATCS. Bug reports, ideas and pull requests are all welcome. ATCS is
released under the MIT licence, and what you contribute is released under it too.

Read first: [the roadmap](../ROADMAP.md) for the ideas already on the list,
[Architecture](../ARCHITECTURE.md) for how the code is organised, and [Building and
testing](building.md) for the build and the tests.
